# Personal Portfolio Website

A responsive personal portfolio website showcasing my projects, technical skills, certifications, and academic background through a clean and user-friendly interface.

## About the Project

This portfolio serves as a central place to present my technical journey, projects, skills, and certifications in an organized and accessible format.

The website is designed to provide a smooth experience across different screen sizes and devices.

## Features

- Responsive design
- Projects showcase
- Technical skills section
- Certifications section
- Personal and academic information
- Contact and social links
- User-friendly navigation

## Technologies

- HTML5
- CSS3
- JavaScript

## Responsive Design

The website is designed to adapt across different devices, including desktops, laptops, tablets, and mobile devices.
